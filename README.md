# CAMEL JAPAN — website preview

キャメルジャパンのホームページ新規開発。GitHub Pagesに静的サイトを公開します。

## 開発

```sh
python3 -m http.server 8765 --directory '2026-10-27_ホームページ新規開発/site'
```

http://localhost:8765/ を開いてください。ビルドは不要です。

## 構成

- `index.html`: 顧客向けホームページ、物件検索、お気に入り、詳細、相談メール作成
- `workspace.html`: 物件管理、媒体掲載候補CSV、相続確認、相談・紹介、月末確認、SNS原稿のローカルデモ
- `credits.html`: データ出典・実装範囲
- `assets/app.js`: サンプル物件、公開条件、検索・フォーム
- `assets/workspace.js`: 運用デモ

`main`へのpushでGitHub ActionsからサイトフォルダだけをPagesへ配信します。
社内調査・売上資料・承認記録などは `.gitignore` の許可リストでGitHubへの送信対象から除外しています。

## 本番化

公開物件はすべて架空です。画面にサンプル表示を維持しています。運用デモは認証されていないブラウザ内の試作であり、個人情報を入力してはいけません。

- 本物の物件を載せる前に広告承諾、写真権利、所在地、交通、権利、接道、用途地域、取引態様、更新日、免許表示などを確認してください。
- SUUMO・アットホームの実配信は未接続です。CSVは独自の確認用形式で、入稿用ではありません。掲載契約・承認された連携方式・媒体仕様を確認してサーバー側のアダプターを実装してください。
- レインズ・登記情報を自動取得しません。利用規程と取得権限の確認が必要です。
- 共有する顧客台帳、相続者リスト、認証、受付メール送信には別のサーバーとアクセス制御が必要です。静的サイトに秘密鍵や個人情報を置かないでください。
- 問い合わせは確認画面からメールアプリを開く方式。サイトから送信済みと表示しません。
- 実アカウントのSNSリンクは確認後に追加します。
- 本番の利用目的・プライバシー表示と正式会社情報を確認後、robotsとnoindexを更新します。

## 検証

```sh
node --check '2026-10-27_ホームページ新規開発/site/assets/app.js'
node --check '2026-10-27_ホームページ新規開発/site/assets/workspace.js'
```

検索、並び順、お気に入り、掲載権限、成約時の販売停止、JSON検証、CSV出力、問い合わせ未送信の表示をブラウザで確認してください。
